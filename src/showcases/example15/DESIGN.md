# Morrow

Editorial home-objects showcase: quiet typography, warm mineral neutrals, restrained terracotta accent, tactile full-bleed imagery. The collection uses a two-column desktop editorial grid and a single-column mobile fallback. Light/dark values are defined in `config.json`; all page selectors are scoped to `.store-example15` or `.e15-product`.

Source brief: the supplied Morrow brief informed this implementation.
